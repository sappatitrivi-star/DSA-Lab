# DSA Lab - Data Structures Laboratory (C Programs)

Record of C programs for the Data Structures Laboratory.
All programs are in the [`All_Programs`](All_Programs) folder, one file per program.

| No. | Program | File |
|-----|---------|------|
| 1 | Singly Linked List - All Operations | `program_01_singly_linked_list.c` |
| 2 | Doubly Linked List - All Operations | `program_02_doubly_linked_list.c` |
| 3 | Circular Doubly Linked List - All Operations | `program_03_circular_doubly_linked_list.c` |
| 4 | Stack Implementation Using Array | `program_04_stack_using_array.c` |
| 5 | Stack Implementation Using Linked List | `program_05_stack_using_linked_list.c` |
| 6 | Queue Implementation Using Array | `program_06_queue_using_array.c` |
| 7 | Queue Implementation Using Linked List | `program_07_queue_using_linked_list.c` |
| 8 | Priority Queue Using Array (ADT) | `program_08_priority_queue_using_array.c` |
| 9 | Deque (Double Ended Queue) Using Circular Array | `program_09_deque_using_circular_array.c` |
| 10 | Hashing - Collision Resolution Techniques | `program_10_hashing_collision_resolution.c` |
| 11 | Binary Search Tree - Insertion, Deletion and Search | `program_11_bst_insert_delete_search.c` |
| 12 | BST - Create, Traverse and Search | `program_12_bst_create_traverse_search.c` |
| 13 | BST - Non-Recursive Inorder, Preorder and Postorder Traversals | `program_13_bst_non_recursive_traversals.c` |
| 14 | Graph of N Cities - BFS and DFS | `program_14_graph_bfs_dfs.c` |
| 15 | All-Pairs Shortest Paths - Floyd-Warshall | `program_15_floyd_warshall_all_pairs_shortest_path.c` |
| 16 | Dijkstra's Shortest Path | `program_16_dijkstra_shortest_path.c` |

## How to compile and run

```
gcc All_Programs/program_01_singly_linked_list.c -o program01 -lm
./program01        # on Windows: program01.exe
```
